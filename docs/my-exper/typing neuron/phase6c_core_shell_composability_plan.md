# Phase 6C：共享核心、条件外壳与可组合性预注册

## 目标与冻结输入

本阶段只读取 Phase 6B 已冻结且通过真实结构化重载的七个赢家，不重新选择样本、不修改语义契约，也不继续
优化 mask。令样本 i 的保留集合为 K_i；按七个赢家中的 identity 保留频次定义 C7、C6+、C5+；严格核心
C7 = ∩K_i，条件外壳 S_i = K_i ∖ C7。

主问题是把集合重叠变成三个可证伪的功能命题：

1. C7 是否比同层同数量随机 identity 更必要；
2. S_i 是否具有条件专属性；
3. K_i 与 K_j 的无重训练 union 是否同时保留两个行为。

## 统一评估

- 模型、数据、canonical prompt、确定性解码和七个冻结语义契约与 Phase 6B 完全一致；
- hook mask 为主筛查，所有 mask 都记录 canonical SHA-256、逐层宽度和精确保留/删除量；
- 每次评估同时记录严格自由生成语义判定及 gold-prefix NLL、KL、top-1 和 margin；
- 任一结果中的“通过”仅指正常终止、单句、无 role/thinking/repetition 垃圾且满足相应样本冻结概念契约；
- 结果按 evaluation id 增量写入，允许确定性 resume，但禁止覆盖已存在的不同结果。

## 实验 A：核心充分性

分别只保留 C7、C6+、C5+，在七个样本上形成 3 × 7 矩阵。该实验不假定严格交集能够独立完成 caption；
若 C7-only 普遍失败而 C6+/C5+ 恢复，说明功能核心更适合定义为频次阈值带而不是硬交集。

## 实验 B：核心必要性

对每个 K_i 额外删除 C7 identity 的 10%、25%、50%、100%，每层按该层 C7 数量确定剂量。前三个剂量使用
10 个确定性 seed，分别从 C7 和 K_i 中抽取同层同数量 identity，形成 paired core-vs-random 干预；100% 剂量
的 C7 删除唯一，评估一次，并与 10 个同层同数量随机删除比较。

主效应为同样本、同剂量下 core 删除相对 matched-random 的语义通过率差和 gold NLL 差。由于 K_i 位于经验
边界，100% 大剂量可能使两组都失败；因此 10%--50% 剂量是主要判别区间。

## 实验 C：条件外壳交换

固定 C7，把来源样本 j 的 S_j 接到目标样本 i，评估完整 7 × 7 矩阵。由于 C7 ∪ S_j = K_j，对角线是冻结
赢家，非对角线是无优化 cross-inference。

为控制外壳大小和逐层宽度，每个来源 j 再生成 3 个随机外壳：从每层 C7 之外抽取与 S_j 同数量的 identity，
并在全部七个目标样本上评估。主效应是 learned shell 相对同列随机外壳的通过率，以及对角线相对非对角线的
优势。

## 实验 D：两两可组合性

对 21 个无序样本对构造 U_ij = K_i ∪ K_j，不重新优化，并用同一 union mask 分别推理 i 和 j。主判据为
pair-level 双任务同时通过率，以及相对各单子网 cross-inference 的恢复。

每个 pair 从 K_i 和 K_j 两个方向各生成 2 个逐层增量匹配的随机扩展：随机加入与真实 union 在该方向每层
新增量相同的 identity。真实 union 只有在双任务通过率优于这些等宽随机扩展时，才支持 identity-specific
可组合性，而不只是“保留更多 neuron”。

## 判据与解释边界

- **共享核心证据**：至少一个非饱和剂量下，core 删除的通过率低于 paired random，且 NLL 恶化方向一致；
- **条件外壳证据**：对角线显著强于非对角线，learned shell 又优于逐层等宽随机 shell；
- **可组合性证据**：真实 union 在不重新优化时同时通过两个样本，并优于等宽随机扩展；
- **反证**：若 random 与 core 同样脆弱，说明效应主要是容量；若随机外壳与 learned shell 相当，说明外壳
  identity 不专属；若 union 恢复仅由更大宽度解释，则不能称为模块组合。

本阶段最多对代表性成功/失败 union 做真实结构化落盘复验。集合 hook 结论必须先完成；结构化复验只验证
实现等价性，不参与挑选或修改统计判据。
