# 导师方案：四模型 × 四数据集神经元响应状态变化率与状态多样性

本文档是从 2026-09 起后续实验的现行规范。旧的 VQAv2、GQA Balanced、CLEVR、VizWiz-VQA
实验及其报告仅作为历史复现记录保留，不得把旧结果混入本方案的主结果表。

## 1. 研究问题

对每个模型，在四个视觉问答数据集上各确定性采样 1,000 个问题样本，观察语言解码器全部 MLP
神经元的样本条件响应状态。对每个神经元统计它在不同样本间切换响应状态的概率，再对模型的全部
MLP 神经元取平均，得到一个 `模型 × 数据集` 的总体响应状态变化率。

本指标描述输入依赖性，不等同于神经元的固定功能类型，也不能单独作为因果证据。

### 3.1 分层配额

设类别（层）`c` 中有 `G_c` 个可采样单位，总目标单位数为 `K`，则理想配额为：

```text
q_c* = K × G_c / sum_c(G_c)
```

- MME 和 ChartQA 的可采样单位是“二题组”，所以 `G_c` 统计组数，`K = N/2 = 500`；先分配组数，
  再展开为 1,000 道题。
- MMBench 的可采样单位是单题，所以 `G_c` 统计题数，`K = N = 1,000`。
- TextVQA 不使用类别配额。

由于 `q_c*` 通常不是整数，统一采用最大余数法：先取 `floor(q_c*)`，再按照小数余数从大到小补足
到 `K`；余数相同时按规范化类别名升序打破平局。若某层容量不足，则将缺额按同一规则重新分配给
仍有容量的层。层内抽样使用固定随机种子且无放回。

### 3.2 必须冻结的采样信息

正式前向计算前必须保存样本清单及其 SHA-256 摘要，并记录数据集 revision、配置、split、随机种子、
分层字段、各层候选数/理想配额/整数配额，以及配对组 ID。MME 和 ChartQA 还必须审计每个入选组
恰好包含两题。若 Hugging Face 实际 schema 不含可直接使用的配对键，必须先根据上游数据定义建立并
验证配对规则，不能假定“同图像的任意两题”就是一组。

## 4. 神经元与响应状态

一个语言解码器 MLP 神经元用 `(l, j)` 唯一索引，其中 `l` 是 decoder layer，`j` 是该层 MLP
中间维度索引。不同模型的层数和 MLP 宽度可以不同；神经元索引只在模型内部有意义，不跨模型对齐。

响应状态仍沿用本项目已冻结的四类定义 `W/V/T/M`：分别表示视觉 token 与用户问题 token 上的
相对强/弱组合。hook、重要性计算、按层归一化、严格阈值和无效观测处理继续遵循
[`ADVISOR_GUIDANCE.md`](ADVISOR_GUIDANCE.md) 的对应定义。

这里的类别 `c` 指神经元响应状态（`W/V/T/M`），不要与采样时的 `category`、`source` 或 `type`
分层类别混淆。

## 5. 变化率

对固定的 `模型 × 数据集` 运行和神经元 `(l,j)`，令：

- `n`：该神经元具有有效响应状态的样本数；完整无效值审计通过时应为 1,000；
- `n_c`：其中响应状态为 `c ∈ {W,V,T,M}` 的样本数，且 `sum_c(n_c)=n`。

神经元在所有**有序、不同样本对**上的响应状态变化率为：

```text
R_(l,j) = (n² - sum_c(n_c²)) / (n(n - 1))
```

分子是响应状态不同的有序样本对数量，分母排除 `x=x'` 的自比较。该式无需显式构造 `n × n`
样本对矩阵，可直接由四类计数精确计算。要求 `n >= 2`；否则该神经元的变化率无定义。

令 `N` 为该模型所有纳入分析且变化率有定义的语言 decoder MLP 神经元集合，则总体变化率为：

```text
R = (1 / |N|) × sum_((l,j) in N) R_(l,j)
```

主结果严格按导师给定定义采用神经元变化率的算术平均。报告同时给出 `|N|`、无效观测总数、
有效样本数不足而被排除的神经元数，并建议补充逐层平均和神经元变化率分布，便于审计平均值。

## 6. 状态熵与有效类别数

总体变化率描述两个不同样本触发不同状态的概率；为了更直接地解释单个神经元在四类状态上的占用
结构，同时报告状态熵和有效类别数。对神经元 `(l,j)`，令
`p_c = n_c / n, c ∈ {V,T,M,W}`，定义未归一化 Shannon 熵（单位为 nat）：

```text
S_(l,j) = -sum_c p_c log(p_c)
```

约定 `p_c = 0` 时 `p_c log(p_c) = 0`。归一化状态熵为：

```text
H_norm_(l,j) = S_(l,j) / log(4)
```

因此 `H_norm ∈ [0,1]`：接近 0 表示神经元几乎稳定为某一类，接近 1 表示四类占用接近均匀，
中间值表示不同程度的状态异质性。

有效类别数使用一阶 Hill number：

```text
K_eff_(l,j) = exp(S_(l,j)) = 4 ** H_norm_(l,j)
```

这里必须区分 `S` 和 `H_norm`：若指数中的熵已经除以 `log(4)`，则应写成 `4 ** H_norm`，不能写成
`exp(H_norm)`；否则最大值只有 `e`，与“四类均匀时等于 4”的解释矛盾。采用上述一致定义后：

- 始终为单一 `V/T/M/W` 状态：`K_eff = 1`；
- 两类、三类或四类等比例出现：`K_eff = 2/3/4`；
- 非整数值表示与该神经元实际状态分布具有相同熵的“等概率类别数”。

主可视化对 16 个运行分别绘制全部 decoder MLP 神经元的 `K_eff` 分布，并采用共享横纵轴组成
`4 模型 × 4 数据集` 小多图。直方图 bin 宽固定为 0.05；平滑曲线只用于阅读分布形状，不参与统计
计算。图中 `[1,1.5)`、`[1.5,2.5)`、`[2.5,3.5)`、`[3.5,4]` 仅作为 near-1/2/3/4 的描述性
参考区间，不是聚类阈值或显著性判断标准。每个运行同时保存均值、中位数、P10/P25/P75/P90 和四个
参考区间占比。

熵和有效类别数是同一份四类占用信息的两种单调变换，不能当作两个相互独立的证据。跨模型比较
仍然是模型内部全部神经元分布的描述性比较，不代表不同架构之间存在神经元一一对应关系。

## 7. 基于 Hellinger 距离的神经元聚簇

对固定的 `模型 × 数据集` 运行，每个神经元 `(l,j)` 由四类响应状态的经验概率向量表示：

```text
p_(l,j) = (p_V, p_T, p_M, p_W),  sum_c p_c = 1
```

两个神经元 `n_a` 和 `n_b` 之间采用 Hellinger 距离：

```text
d_H(n_a,n_b) = (1 / sqrt(2)) × sqrt(sum_c (sqrt(p_c^n_a) - sqrt(p_c^n_b))²)
```

其取值范围为 `[0,1]`：`0` 表示两个状态概率分布完全相同，`1` 表示二者的概率质量落在完全不重叠
的类别上。类别轴固定为 `V,T,M,W`，不得在不同运行中改变顺序。

使用标准 Average-Linkage 层次聚簇。两个簇 `A,B` 的距离定义为全部跨簇神经元对距离的算术平均：

```text
D_avg(A,B) = (1 / (|A||B|)) × sum_(a in A) sum_(b in B) d_H(a,b)
```

在 dendrogram 的 cophenetic distance `d_H = 0.20` 处切割得到聚簇。每个 `模型 × 数据集` 独立聚簇；
不同运行中的 cluster ID 只在各自运行内有效，不可直接视为跨模型或跨数据集对应簇。

### 7.1 当前可执行范围

标准 Average-Linkage 需要 `O(N²)` 两两距离存储和计算。现有每组运行包含 147,456–352,256 个神经元；
仅 float64 condensed distance vector 就约需 81.0–462.2 GiB，尚未计入 linkage 工作内存。即使先合并
完全重复的概率向量，每组仍有约 11.9 万–31.1 万个唯一向量，不能把去重视为可行的全量方案。

因此当前结果明确标记为 `pilot`：每组按层神经元数量比例、固定种子、无放回抽取 4,096 个真实神经元，
然后在该样本内部精确计算全部 Hellinger 距离并执行无连接约束的标准 Average-Linkage。保存内容包括：

- 分层抽样清单和每个入选 `(layer,neuron)` 的 cluster ID；
- 完整 linkage matrix；
- 各簇大小、四类概率中心和到中心的 Hellinger 距离摘要；
- 源 profile、抽样归属、簇摘要和 linkage 文件的 SHA-256；
- 全量距离矩阵的存储量估算。

该 pilot 用于验证距离、阈值、簇数量和后续展示设计，不冒充全部神经元的精确聚簇。全量阶段需要另行
明确近似方法并进行抽样规模/随机种子稳定性分析；聚簇呈现形式暂不冻结。

## 8. 六种无序状态对分解

四类响应状态产生六个无序状态对，固定顺序为 `VT, VM, VW, TM, TW, MW`。对神经元 `(l,j)`，随机抽取
两个不同样本时分别落在状态 `c_1` 和 `c_2`（不计顺序）的概率为：

```text
R^(l,j)_(c_1c_2) = 2 N^(l,j)_(c_1) N^(l,j)_(c_2) / (N(N-1)),  c_1 != c_2
```

六项必须逐神经元精确满足：

```text
R^(l,j) = R^(l,j)_VT + R^(l,j)_VM + R^(l,j)_VW
          + R^(l,j)_TM + R^(l,j)_TW + R^(l,j)_MW
```

模型在某数据集上的绝对状态对贡献先对神经元取算术平均：

```text
R_(c_1c_2) = (1 / |N|) sum_((l,j) in N) R^(l,j)_(c_1c_2)
```

因此六个总体贡献之和等于第 5 节的总体变化率 `R`。构成图的柱高使用
`C_(c_1c_2) = R_(c_1c_2) / R`，即**先平均绝对贡献，再归一化**。不得先计算每个神经元的
`R^(l,j)_(c_1c_2) / R^(l,j)` 再平均：该量对 `R^(l,j)=0` 的稳定神经元无定义，而且会使低变化率与
高变化率神经元获得同样权重，改变当前总体 `R` 的分解口径。

完整结果、16 张单图、共享纵轴的 4×4 总览图和机器可读表见
[`reports/advisor_2026_09/advisor_2026_09_state_pairs.md`](reports/advisor_2026_09/advisor_2026_09_state_pairs.md)。
16 个运行中逐神经元六项求和与原变化率的最大绝对残差为 `2.220446e-16`。

## 9. 逐层四状态平均分布

为了进一步研究不同响应状态的神经元对答案生成的影响，先固定一个描述性基线：统计每个模型在每个
数据集上，各 decoder 层中 `V/T/M/W` 四种状态的平均占比。对类别 `c` 和第 `l` 层定义：

```text
p_c^(l) = (1 / |N^(l)|) sum_((l,j) in N^(l)) N_c^(l,j) / N
```

其中 `N^(l)` 是第 `l` 层的全部真实 MLP 神经元，`N=1000`。计算顺序是：先对每个神经元计算其
1,000 个样本中的状态频率 `N_c/N`，再在同层神经元间取算术平均。每层必须满足：

```text
p_V^(l) + p_T^(l) + p_M^(l) + p_W^(l) = 1
```

不同架构保留真实深度和 MLP 宽度：LLaVA 为 32 层、Qwen3-VL 为 28 层、Qwen3.5 为 24 层、Gemma
为 35 层；Gemma 的 6,144/12,288 宽度层分别按实际神经元计算，不补假神经元，也不把模型补齐到
统一层数。完整的 476 层结果、16 张单图和 4×4 总览见
[`reports/advisor_2026_09/advisor_2026_09_layerwise_states.md`](reports/advisor_2026_09/advisor_2026_09_layerwise_states.md)。
所有层四项之和相对 1 的最大绝对残差为 `1.110223e-16`。

该结果只回答各层四种响应状态“出现得多不多”，尚未回答某类神经元对生成答案的影响是否更大；后者
需要冻结神经元选择规则、干预方式、对照组和答案质量指标后再做消融或干预实验。

## 10. 四状态神经元消融实验

目标是在删除数量完全相同的前提下，比较 `V/T/M/W` 四类神经元对模型答案质量的影响。继续使用每个
数据集已经冻结的 1,000 个样本。MME、TextVQA 和 ChartQA 直接读取上一阶段已经冻结的逐样本
`q^V,q^T`、`V/T/M/W` 类别及响应强度，不重新前向计算，也不因答案生成 prompt 而改变分类。MMBench
同样直接读取修正后的冻结结果；该结果已经用“图像 + 问题 + 有效选项”计算，并明确排除了 dataset
的 `hint` 和“只输出选项字母”这类生成约束。答案生成时可单独追加格式约束。

每层删除数固定为：

```text
k_l = max(1, floor(0.01 × d_ff^(l)))
```

因此同一层的 14 个概念条件删除完全相同数量的神经元；Gemma 的不同宽度层按各自真实 `d_ff` 计算。
四类状态内的响应强度定义为：

```text
s_V = q^V,  s_T = q^T,  s_M = q^V + q^T,  s_W = q^V + q^T
```

概念条件共 `1+4+4+4+1=14` 个：Baseline；四类 state 内 Random；四类 state 内 Max；四类 state 内
Min；以及忽略状态的 Global Random。四类 Random 和 Global Random 各做 10 个固定种子、无放回重复，
因此每个 `模型 × 数据集` 实际执行 `1 + 4×10 + 4 + 4 + 10 = 59` 次完整评估。标准差先在每次重复的
1,000 样本数据集分数上计算，不能把 10,000 个样本级分数直接混合后计算。

删除操作通过 down projection 的 forward-pre hook 将入选的 post-gating 坐标置零实现。对
`y=W_down z` 而言，这与对当前 forward 使用 `W_down[:,S]=0` 完全等价，同时不原地修改或累积破坏模型
权重。每个样本和条件保存选择种子及入选索引 SHA-256，支持中断续跑和复核。

评估指标固定为：

- MME：yes/no Accuracy；
- MMBench：选项 Accuracy；
- TextVQA：官方 VQA 答案规范化及 leave-one-annotator-out Soft Accuracy；
- ChartQA：数值答案相对误差不超过 5%，非数值答案精确匹配的 Relaxed Accuracy。

作图使用相对同一未消融 Baseline 的分数下降（百分点）：正值表示性能变差，负值表示性能改善；state
内 Random 使用 10 次均值和标准差，Global Random 以虚线和 `±1 SD` 带表示。当前阶段先固定 1%，后续
扩展比例时必须保留相同样本、prompt、解码配置、随机种子体系和评价实现。

## 13. 结果分析边界

- 判别式与生成式数据集的题型、答案空间和提示模板不同，跨数据集数值只能作描述性比较。
- 不同模型的神经元数不同；总体 `R` 是模型内部的神经元平均，不是神经元一一对应比较。
- 较高的 `R` 表示响应状态更依赖输入样本，不自动意味着模型能力更强、推理更深或神经元更重要。
- 应结合任务准确率/生成指标检查模型是否正常完成任务，避免把模型失效或模板错误解释为神经元现象。
- 本方案没有构造反事实干预；结果是观测性输入依赖统计，不作因果表述。
- `H_norm` 与 `K_eff` 是确定性单调对应关系，不应被当作相互独立的验证指标。
- near-1/2/3/4 区间只用于辅助阅读连续分布，不得把区间归属表述成真实的离散神经元类型。

- Hellinger pilot 的簇数量和簇占比只描述确定性抽取的 4,096 个神经元；未经稳定性分析不得外推为全量
  神经元的精确簇结构。
- Average-Linkage 的 `0.20` 是预先指定的 dendrogram 切割阈值，不代表自然类别边界或统计显著性。
- 状态对构成百分比是对总体变化率 `R` 的描述性分解；它不表示两类状态之间存在方向性转换，也不表示
  任一状态对具有因果作用。构成百分比与绝对 `R_ab` 必须同时保留，不能只比较归一化柱高。
- 逐层 `V/T/M/W` 占比衡量状态占用频率，不衡量对答案的边际贡献。某层或某类占比更高，不等于消融后
  答案质量下降更多；在正式干预前不得将这张分布图表述为答案影响结果。
- 消融结果支持的是在当前 1% 比例、当前选择规则和当前解码设置下的干预比较；不能直接外推到更高比例、
  其他解码策略或“该类别全部神经元”的总体因果效应。

## 14. 导师追加实验：A1 与 A2 的弱响应神经元识别对照

在已完成五状态 `V/T/M/C/W` 分类及 W/C 的 1% 答案生成消融之后，比较“先按输入位置分组，再识别
W”与“直接把全部输入位置合并，再识别 W”。继续使用同一四模型 × 四数据集、每组 1,000 个冻结样本，
以及前述答案生成实验的模型版本、图像、问题、有效选项、生成约束、原生 chat template / System Prompt、
特殊 token、评分函数和确定性解码设置；不得把早期“原始问题 + 默认模板”输入或示例模拟分数混入本实验。

设 `S_V`、`S_T`、`S_C` 分别为视觉、用户问题正文、控制/提示模板输入位置，彼此不重叠；排除 padding。
`S_C` 包含输入中实际存在的系统提示、模板及特殊 token 等非视觉、非问题正文位置，不等于某一个
指定 token。对任意非空位置集合 `S`，沿用第 2 节的 post-gating down-projection 加权 RMS 重要性
`I^(S)_(l,j)(x)`，并在样本 `x`、层 `l` 内按真实 `d_ff^(l)` 个神经元归一化：

```text
q^(S)_(l,j)(x) = I^(S)_(l,j)(x) / sum_k I^(S)_(l,k)(x)
tau_l = 1 / d_ff^(l)
```

两种方法的 W 池及池内排序强度固定如下；阈值**包含等号**，不把 `q=tau_l` 视为强响应：

```text
A1: W_A1(x,l) = {j: q^V_(l,j)(x) <= tau_l,
                     q^T_(l,j)(x) <= tau_l,
                     q^C_(l,j)(x) <= tau_l}
    s_A1(l,j,x) = q^V_(l,j)(x) + q^T_(l,j)(x) + q^C_(l,j)(x)

A2: S_all = S_V union S_T union S_C
    q^all_(l,j)(x) = I^(S_all)_(l,j)(x) / sum_k I^(S_all)_(l,k)(x)
    W_A2(x,l) = {j: q^all_(l,j)(x) <= tau_l}
    s_A2(l,j,x) = q^all_(l,j)(x)
```

`q^all` 必须直接对合并位置的 post-gating 激活重新计算 RMS 和归一化；它通常**不等于**
`q^V+q^T+q^C`，也不能从已经分别归一化的三个 `q` 反推。A1 可复用五状态实验冻结的逐样本
`q^V,q^T,q^C` 和 W 类标记；A2 应在相同的模型输入上单独计算并保存逐样本 `q^all`，以便中断续跑
及复核。空位置集合、零总重要性或非有限数值均为无效观测，不能默认归入 W。

对每个样本、每个真实 decoder MLP 层及 A1/A2 各自的 W 池，分别设置目标删除比例
`r ∈ {1%,5%,10%,15%,20%}`，目标数 `k_l(r)=max(1,floor(r × d_ff^(l)))`。按对应 `s_A1` 或 `s_A2`
从小到大选取；强度相同时用神经元索引升序打破平局。若 W 池不足 `k_l(r)`，只删除池内全部神经元，
不得从非 W 类补足。删除仍使用 down-projection 输入的 post-gating 坐标置零，且每个条件独立恢复
未修改的模型状态。一个未消融 Baseline 与 `A1/A2 × 5` 个删除条件组成每组 11 次评估；完整矩阵为
`16 × 1,000 × 11 = 176,000` 条答案生成记录，另需保存 A2 的直接 pooled 重要性计算结果。

每个条件保存样本 ID、方法、目标比例、实际删除数、可用 W 数、短缺层数、入选索引摘要、原始答案
和任务分数。实际删除比例定义为该样本被删除神经元总数除以该模型全部真实 decoder MLP 神经元数，
再对 1,000 个样本取平均；同时报告目标比例，不能以目标代替实际比例。四种数据集指标与第 10 节
保持一致。每个 `模型 × 数据集` 绘制 A1/A2 的分数—目标比例曲线，0% 为同一 Baseline，并在图下列出
两种方法各比例的实际删除百分比；汇总表至少给出分数及相对 Baseline 的百分点变化。

本对照用于检验模态/提示位置划分对 W 识别是否带来可观察的答案质量差异。若两法实际删除比例或 W
池大小不同，不能仅凭相同**目标**比例的曲线间距断言划分方式更优；应并列报告实际比例与池大小，
必要时再设计等实际删除数的补充对照。导师提供的曲线与绘图代码仅是**模拟示例**，其中 1 个百分点
损失线不是已批准的性能容忍阈值，也不是非劣效性统计结论；正式图只能使用实测数据，不预设 A1
优于 A2。

## 15. 第七步：模态感知重要性的累积分布

沿用第五步冻结的同一批输入及每个样本、真实 decoder 层、神经元的
`q^V,q^T,q^C`，定义 `s_(l,j)(x)=q^V_(l,j)(x)+q^T_(l,j)(x)+q^C_(l,j)(x)`。
本步统计**全部** MLP 神经元，不仅是 W 类。对每个样本和层，按 `s` 升序排列，
以该层总分为分母，计算最低分前 `u` 比例神经元的累计分数占比 `G_l(u;x)`。
包括 `(0,0)` 和 `(1,1)` 端点；不同层宽度通过线性插值对齐同一 `u` 网格，
不做平滑拟合。随后对真实层等权平均得到 `bar G(u;x)`，再对冻结数据集的
1,000 个样本等权平均得到 `G_D(u)`。层总分必须为正，分数必须非负且有限，
否则该样本无效并报告，不以零或模拟数据填补。

每个模型 × 数据集分别绘制 `G_D(u)`、跨样本 `bar G(u;x)` 的第 10–90 百分位
阴影带，以及均匀分数参考线 `y=u`；标出数据集均值曲线最大竖直差
`argmax_u[u-G_D(u)]` 的最早网格点，记录对应 `u` 和累计分数占比。此点只是
分布形状的**候选拐点**，不是已经验证的安全删除比例；阴影带表示样本异质性，
不是均值的置信区间。另保存可复核的数值曲线和来源 manifest。

本步回答“重要性是否集中、最低分神经元承担多少归一化响应”，不直接回答
“删除后精度下降多少”。不能把累计响应占比当成答案质量损失，也不能把候选
拐点当成第六步 1%–20% 删除实验的性能阈值。导师给出的图和代码是模拟示例，
其中的数值不得用作正式实验结果。

## 16. 第八步：基于逐样本累计曲线的自适应剪枝

对第 15 节同一冻结输入和每个样本的 `bar G(u;x)`，比较两种**逐样本**比例选择法：

```text
A1: r*(x) = argmax_{u in [0,1]} [u - bar G(u;x)]
A2: r_epsilon(x) = max{u in [0,1]: bar G(u;x) <= epsilon}, epsilon = 0.05
```

A1 的并列极大点选最小的 `u`；A2 在单调曲线的阈值交点处线性插值。
两法均使用所有真实 decoder MLP 神经元的 `s=q^V+q^T+q^C` 升序排名，
不局限于 W 类；同分时按神经元索引升序。每个样本在**所有层使用同一比例**，
每层实际删除数为 `floor(r × d_ff^(l))`，所以实际删除比例和实际累计分数占比
要按离散选择结果另行报告，不能以连续曲线的候选值代替。A2 的 `epsilon`
约束的是层等权平均累计分数，不保证任一单独层低于 5%。

沿用第六步冻结的模型、图像、提示模板/System Prompt、特殊 token、生成约束、
确定性解码、数据集评分与 1,000 样本顺序。每个样本分别比较未剪枝 Baseline、
A1、A2 的答案；若第六步 Baseline 的模型、输入、生成设置和样本顺序逐项一致，
可复用该冻结答案并明确记录来源，否则重新生成。A1/A2 各自独立安装、卸载
置零 hook，不能将前一条件的删除累积到后一条件。保存样本 ID、方法、
连续候选比例、每层离散删除数、实际总体删除比例、候选与实际累计分数占比、
入选索引摘要、答案和逐题分数，支持中断续跑。首先在 GPU 上小样本验证选择
和恢复机制，再完整运行四模型 × 四数据集。

每组展示 A1/A2 **实际**剪枝比例分布与均值，以及对 Baseline 的配对任务分数
变化。MME/ChartQA 的配对题按图像/图表组进行 group bootstrap；其它数据集
按真实独立采样单位分组。误差条是配对 group-bootstrap 95% 置信区间，不能把
单题独立抽样的区间用于成对样本。并列报告质量与实际删除量，不能因 A1/A2
剪枝比例不同就把二者差异归因于比例选择规则优劣。此法需要在同一输入上先
计算 `q`，实际推理成本包括该预先前向过程；均匀逐层比例只是有利于后续结构化
实现的设计约束，置零消融本身不证明墙钟延迟或显存已经下降。导师提供的图和
绘图代码仅为**模拟示例**，不得将图中比例、准确率或置信区间填入正式结果。

## 17. 第九步：A2 累计响应预算 ε 的扫描

第八步表明，最大竖直差拐点 A1 对应的实际删除量过大；A2 以累计响应分数预算
约束删除量，更适合继续考察。但 `ε=0.05` 只是起始设置，不能据此认定为最优值。
本步只扫描 A2，预先固定 `E={0.05,0.10,0.15,0.20,0.25,0.30}`，观察质量与
实际删除量的权衡；不重新定义 `s=q^V+q^T+q^C`，也不改变第八步的剪枝机制。

对每个样本 `x` 和每个 `ε∈E`，从同一条冻结的样本曲线计算
`r_ε(x)=max{u∈[0,1]: bar G(u;x)≤ε}`；在阈值交点线性插值。各真实 decoder MLP
层使用同一 `r_ε(x)`，按 `s_(l,j)(x)` 升序删除
`floor(r_ε(x)×d_ff^(l))` 个神经元，同分时按索引升序。记录每层实际删除数、
全模型实际删除比例，以及删除位置的层等权平均累计分数占比。由于取整，
**横轴 ε 不是实际剪枝率**；正式结果必须同时报告二者。按同一样本的固定排名，
随 `ε` 增大入选集合应单调嵌套；实际累计分数占比不得超过对应预算（允许
浮点误差）。这些是运行前的小样本检查和完整结果的审计条件。

沿用第八步相同的 4 模型 × 4 数据集、每组 1,000 个冻结样本、System Prompt、
chat template、图像和特殊 token、确定性解码、评分规则及置零 hook。每个
`模型×数据集×ε` 独立恢复未消融状态，不让不同 ε 的 hook 或缓存相互污染；
保留逐样本 ID、组 ID、候选与实际比例、入选索引摘要、原始答案和逐题分数，
支持断点续跑。只有在 run config、样本清单哈希、输入/生成/评分设置和选择
实现逐项一致时，才复用第八步的 Baseline 与 `ε=0.05` 结果；否则重跑该条件。
完整矩阵有 16×6=96 个 A2 条件、共 96,000 条剪枝答案；若所有复用检查通过，
新增需要生成的是其余 5 个 ε 的 80,000 条答案。先做少量样本 smoke test，
再按设备空闲情况调度正式运行。

每个模型×数据集绘制一张**任务分数—ε 折线图**：横轴按上述六个 ε 值，纵轴
使用该数据集既有任务评分的百分比（MME/MMBench 为准确率，TextVQA 为软准确率，
ChartQA 为宽松准确率），标出共享 Baseline 的水平虚线；图下另列每点的样本
平均实际剪枝率，或增加不与分数共用纵轴的独立小面板。可用按真实独立单位
分组的配对 bootstrap 给出每点相对 Baseline 的 95% 区间：MME/ChartQA 按
图像/图表配对组，其余按对应独立单位；区间必须来自实测逐题分数，不能把
样本间剪枝率分布当作精度不确定性。保存 16 张图、条件级汇总表及逐样本记录。

比较 ε 时同时看质量损失、实际删除量及其样本分布，不能单凭较高任务分数
就选最小 ε，也不能单凭更多删除就选最大 ε。若要宣布“合适”或“最大可接受”
ε，须先明确允许的分数下降/置信区间规则，并检查所有数据集及明显脆弱的
模型—数据集组合；未预先约定容忍阈值时，只报告质量—删除量的 Pareto 权衡，
不事后把某个点包装成安全阈值。置零消融只验证答案质量，不等于已经获得
实际推理加速。配套示例图是**纯模拟数据**，不得填入正式结果表。

## 18. 第十步（自主探索方案）：相同平均响应预算下的逐层非均匀剪枝

本节是用户提出的自主探索，沿用导师的实验组织方式。2026-10-11 经用户授权启动正式实验。
目标是在第九步相同的层等权平均响应预算下，解除各层剪枝比例相同的约束，尽可能多删神经元，
并测量答案质量。比较 U（第九步均匀比例）与 N（本步非均匀比例）；本轮不加入等删除量对照。

### 18.1 逐样本选择算法

1. 读取冻结输入上未消融前向得到的每个真实 decoder 层的 `qV,qT,qC`，计算
   `s_lj(x)=qV_lj(x)+qT_lj(x)+qC_lj(x)`。候选是全部真实 FFN 神经元，不限 W 类，排除 padding。
   检查分数有限、非负、每层总分严格为正；异常时停止对应样本并记录，不静默填补。
2. 定义 `a_lj=s_lj/sum_j(s_lj)`，单个神经元的预算成本为 `c_lj=a_lj/L`。
   这样删除集合 D 的成本恰为 `B(D;x)=sum_(l,j in D)c_lj`，也就是各层删除分数占比的平均。
   不直接跨层排序未归一化的 s，不把逐层预算分别限制为 ε。
3. 按 `(c_lj, layer_index, neuron_index)` 排序全部神经元，同分确定性打破并列。
   用 float64 累计，取满足累计成本不超过 ε 的最长前缀，含所有可选的零成本神经元。
   `K*=max{K: sum_(i=1)^K c_(i) <= ε}`。按层拆回删除索引，得到 `k_l` 和 `r_l=k_l/d_l`。
   这等价于在 `mean_l G_l(k_l/d_l;x)<=ε` 下最大化 `sum_l k_l`。
   每个神经元收益均为一个删除名额，所以最低成本前缀是该离散问题的最优解。
4. 全模型实际剪枝率为 `R=sum_l k_l/sum_l d_l`；记录各层响应占比 `b_l=sum_selected a_lj`
   和实际平均占比 `B=mean_l b_l`。不同层宽度必须使用真实 d_l；不能以层比例的简单平均代替 R。
   本轮无额外层上限/保护层：某层可能被全部消融，须报告该情况；若加保护，需另命名为变体。
5. ε 仍为 `0.05/0.10/0.15/0.20/0.25/0.30`。同一样本一次排序供六个预算复用，选择集合逐级嵌套。
   当前均匀 U 的离散方案是 N 的可行方案，因此逐样本应有 `K_N>=K_U`，但不保证精度更好。

r=0.05/0.10/.../0.50，不限于 W 池；同分按层号和神经元号排序。

该下限及其触发层必须能从原始删除数与最终宽度追溯。需补回时优先恢复已删集合中最高分单元。
每层原始宽度须为 8 的倍数，否则停止。记录对齐前删除数、对齐后宽度、实际删除率、
保留索引与摘要及物理参数量。独立取整后 U/N 实际数量不保证相等，主图称“同目标比例”。
如需严格归因于层间分配，再另做对齐后等总数量控制，不能把当前结果表述成严格等参数比较。

四个数据集从相同 pinned revision 获取 1,024 个唯一请求，按图像 SHA256 整组确定性选择，
排除校准集图像和样本 ID，固定 seed namespace throughput-20261022。保留图像原始 bytes、
source_index、题目、答案、选项和摘要；同数据集各模型复用同一清单和批次顺序。
数量不足或原始数据不可访问即停止，不重复旧样本凑数。此为吞吐量工作负载，整图分组抽样
不保证复现以前按类别分层的样本比例；不得直接与旧 1,000 样本的精度均值相比。
沿用 evaluation_prompt 与本地模型 chat template，包含 System Prompt/特殊 token；左填充批处理。

### 22.2 正确性与计时口径

每模型×数据集先验证 U/N 的 10%、30%，使用前两个新请求，分别检查 batch=1、2：
批处理去 padding 后的 token 与逐条处理一致；置零和物理裁剪的末 token 全词表 logits
以 FP32 数值等价（相对 RMS <=1e-5、最大绝对误差 <=1e-3）及 BF16 最多四 token
确定性生成序列完全一致作为联合门槛；两种精度均拒绝非有限 logits。完整记录 BF16
数值偏差及原 1% RMS/0.5 最大绝对误差阈值是否通过，但该阈值不再作为放行条件。
这是首个方案 FP32 等价、BF16 答案一致但 RMS 超限后，经用户明确同意的判定修订；
保留原失败和诊断记录，重新运行四套正式验证，不将诊断文件直接作为放行凭据。
LLaVA 的 FP32 验证在 CPU 完成以避免24GB显存不足，其余模型默认 GPU；所有 BF16
验证与正式测速均在指定 GPU。生成一致性仅覆盖这两个请求和最多四个输出 token，
不是对所有输入等价的证明。CPU 单元测试另检查 bias、不同层宽及对齐补回规则。
通过文件绑定代码、数据、架构、运行环境和对应 FP32 证明哈希，任一失败停止。

固定单卡、BF16、SDPA、eval/inference_mode、use_cache=True、do_sample=False、max_new_tokens=32。
先在 CPU 构造并裁剪，再整体移到单 GPU；测速不允许 CPU offload。
主图采用“GPU 服务吞吐量”：输入先在 CPU 预处理，各 batch 计时包含 H2D、视觉编码、
prefill、decode；每段前后 synchronize，总时长为全部 batch 的这些时间段之和，req/s=1024/总时长。
不计模型加载、校准、物理裁剪、CPU 图像预处理、D2H/解码评分和 batch 间 CPU 间隔；
因此此数值不是包含数据加载、排队和在线校准的端到端系统吞吐量。
每条件预热 3 batch，完整测量 3 遍，报告 req/s 中位数和各次值，同时记录生成 token 总数、
任务得分、峰值 allocated/reserved 显存及软件/硬件标识。
试点另做 min_new_tokens=max_new_tokens=32 的固定输出长度复核（batch=1）。

batch_size=1/2/4/8/16/32/64，按每架构与比例递增。仅 CUDA OOM 标记 oom，且该条件
三遍结果均作无效；更大 batch 标记 skipped_after_oom。普通错误终止并保留 traceback。
不以部分请求结果填完整单元格。完成条件原子保存 JSON，中断后整条件重跑；配置变更拒绝续接。
每次 GPU 子任务前检查空闲（占用 <=1 GiB，util <=10%）；忙碌则退出，不停止其他进程。
