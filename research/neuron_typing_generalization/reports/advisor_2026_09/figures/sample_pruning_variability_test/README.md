# 非均匀剪枝：样本间差异小测试

本目录为独立探索性测试，不纳入导师指导。沿用冻结的非均匀剪枝实验，不进行新推理，
不评价精度变化或实际加速。

- 条件：四模型 × 四数据集，ε=0.05/0.15/0.30，各组 1,000 个样本。
- 总剪枝率：K(x)/sum_l d_l，不是各层剪枝率的简单平均。
- 逐层比例：k_l(x)/d_l，显示样本均值和 P10–P90；CSV 另存样本标准差（ddof=1）。
- 集合：用原始 qV+qT+qC 重建 c 的稳定全局排序，真实层宽度，不含填充；
  同成本按层号、神经元编号打破并列，预算边界容差 1e-12。
  逐样本核对 sample_id、总删除数、每层删除数及原实验 selection_sha256。
- 样本对：seed=20261022，随机均匀抽取 2,000 个不重复、不同 group_id 的无序样本对。
  同一组的三档预算使用同样的样本对。抽样单位是样本对，不是等权的题组对；
  同图/同题组被排除，但样本对之间仍可能共享样本，故不作为独立重复做显著性推断。
- Jaccard = |A∩B|/|A∪B|。
- 随机参照：分别固定两样本全模型总删除数，或更严格地固定每层删除数。
  全局随机的期望交集 I0=Ka*Kb/D；逐层匹配随机的期望交集
  IL=sum_l ka_l*kb_l/d_l。图中使用 IL/(Ka+Kb−IL)，只是以期望交集代入的
  Jaccard 参照，不是 E[Jaccard] 的精确值，也不是一次实测随机剪枝结果。
- adjusted_overlap=(|A∩B|−IL)/(min(Ka,Kb)−IL)，分母为零时记为 NaN；
  这是基于逐层随机参照的调整重合度，而非任务性能指标。
- 箱线图：中线为中位数，箱体 P25–P75，须 P10–P90，不绘制尾部样本点。
  左图纵轴按组聚焦；中、右图使用统一百分比尺度。所有区间都是分布范围而非置信区间。

复现入口（仓库根目录）：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python research/neuron_typing_generalization/pipelines/test_sample_pruning_variability_2026_10.py --workers 4 --resume
python research/neuron_typing_generalization/pipelines/test_sample_pruning_variability_2026_10.py --replot-only
```

长任务使用 tmux。每组 JSON 记录来源文件 SHA256 与完成标记；重绘时复核来源。
CSV 的比例均为 0–1 小数；图上为百分比；标准差乘以 100 后的单位是百分点。
`__samples.csv`、`__layers.csv`、`__pairs.csv` 分别保留三种粒度的数据。

## 本次结果

2026-10-22 完成 16 组、48 个预算条件，48,000 个删除集合摘要与原实验完全一致；
统计 96,000 个样本对×预算记录。相关单元测试共 18 项通过。
下表为 16 组等权平均；标准差先在每组样本内计算，逐层标准差还先在该模型层间平均。
这里不是把所有模型样本混在一起计算标准差。

| ε | 总剪枝率标准差（pp） | 逐层剪枝率标准差（pp） | 平均 Jaccard | 逐层匹配随机参照 |
|---|---:|---:|---:|---:|
| 0.05 | 0.177 | 0.614 | 46.00% | 13.44% |
| 0.15 | 0.277 | 0.819 | 56.84% | 22.46% |
| 0.30 | 0.323 | 0.780 | 68.98% | 36.68% |

48 个条件的总剪枝率标准差为 0.070–0.602 pp；逐层标准差的层均值为
0.422–1.194 pp，个别层最高约 3.514 pp。因此总数量稳定不代表每层同样稳定。
48 个条件的实测平均 Jaccard 都高于逐层随机参照（描述性结果，未做显著性检验）。
集合并非完全固定：存在共同偏好的神经元，也有样本相关变化。
这些结果尚不能证明固定 mask 可以替代逐样本 mask；是否能替代仍需精度对照实验。
